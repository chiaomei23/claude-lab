# 巧妹 Wonderland｜平面設計師作品集

平面設計師巧妹的個人 Landing Page，用來介紹服務項目、展示精選作品，並提供接案聯繫管道。

## 網站功能

- **頁首導覽**：品牌標誌與「精選作品」錨點連結，點擊後平滑捲動至對應區塊。
- **英雄區塊**：呈現主標語與自我介紹，並提供「與我聯繫」（開啟郵件）及「觀看作品」兩個行動按鈕。
- **精選作品**：以卡片展示品牌識別、包裝設計、活動主視覺三類作品。
- **RWD 響應式設計**：作品區在 900px 以下改為單欄，標題字級與換行、按鈕寬度也會依手機螢幕調整，並加大導覽連結的觸控範圍。
- **視覺與動畫**：深色漸層星空背景、旋轉光環裝飾及區塊淡入效果；若系統設定為減少動態效果，動畫會自動關閉。

## 使用技術

- **HTML**：語意化標籤與無障礙屬性。
- **CSS**：CSS 變數、Flexbox、Grid、`clamp()`、Media Queries 與 Keyframes 動畫，全部寫在 `index.html` 內。
- **字型**：透過 Google Fonts 載入 Inter，中文使用系統黑體。

本專案未使用 JavaScript，也不需要安裝套件或進行建置。

## 如何用瀏覽器開啟

**方法一：直接開啟檔案**

在檔案總管（Finder）中找到 `index.html`，雙擊即可用預設瀏覽器開啟，或將檔案拖曳到瀏覽器視窗中。

**方法二：使用終端機（macOS）**

```bash
open index.html
```

> 英文字型需要網路連線才能載入；離線時會改用系統字型，版面仍可正常瀏覽。
